# RS4S Hub — Research by Students, for Students

The official landing page for **RS4S Hub (Research by Students 4 Students)**, a platform designed for university students to discover and access research tools, guidance, mentorship, opportunities, and community resources.

![RS4S Hub Screenshot](/public/hero.png)

## Overview

RS4S Hub provides an intuitive, student-centric gateway to the university's research ecosystem:
- **Collapsible Navigation**: Responsive sidebar featuring quick access to core sections (`Start Here`, `Learn`, `Connect`, `Do Research`, `Opportunities Hub`, `Share`, `Upcoming Events`, `Resources & Templates`, `FAQ`, `Community Guidelines`, `Contact Us`).
- **Research Journey Roadmap**: Interactive 6-step sequential pathway helping students navigate from novice to presenter:
  1. *I know nothing about research* → **Start here**
  2. *I want to learn a skill* → **Research Essentials**
  3. *I need guidance* → **Mentorship**
  4. *I want a project* → **Research Opportunities**
  5. *I already have a project* → **Project Support**
  6. *I want to share my experience* → **Present with RS4S**
- **Resource Hub**: Dedicated modular cards for Learn, Connect, Do Research, Opportunities Hub, Share, Upcoming Events, and Resources & Templates.
- **Community & Mission**: Quick links for Announcements, WhatsApp student network, and the RS4S Mission.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 6
- **Styling**: Tailwind CSS v4
- **Typography**: Satoshi (Fontshare)
- **Icons**: Lucide React
- **Notifications**: Built-in responsive feedback toast system

## Getting Started

### Prerequisites
- Node.js 18+
- npm 9+

### Installation & Local Development

```bash
# Clone repository
git clone https://github.com/anashamidoglu/rs4s-hub.git
cd rs4s-hub

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
